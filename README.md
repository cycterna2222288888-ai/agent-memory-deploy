# agent-memory-deploy

Sales material for a service offer: deploying and supporting the open-source
[Metronix Memory](https://github.com/mtrnix/metronix-memory) (Apache-2.0) on a customer's
own servers. This is an independent implementation-partner offer, not the Metronix project;
the name is used only to identify the software. No Metronix logo is used.

| Path | What it is |
|------|------------|
| `landing/index.html` | One-page site. Static, no frameworks, no external requests. |

## Placeholders to fill before publishing the page

- `https://BOOKING_URL`: the booking link, used by the single CTA button.
- `https://example.com/`: the real domain, in the canonical, `og:url` and JSON-LD tags.
- The demo video box, marked `PLACEHOLDER: 2-minute demo video`.
- `[Your name / company]` in the footer.

Preview locally: `open landing/index.html`. Deploy by copying `landing/` to any static host.
